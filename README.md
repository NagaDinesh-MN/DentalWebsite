# BrightSmile Dental Clinic

A realistic, mobile-responsive dental clinic website for Chennai, India.

## Included
- Responsive navigation and smooth scrolling
- Hero, services, pricing, technology and gallery sections
- Patient testimonials and FAQ accordion
- Appointment form with validation and success state
- Click-to-call and WhatsApp actions
- Google Maps embed
- Scroll-to-top control and branded loader

## Deployment
This repository is prepared for public static hosting. Connect it to a free host such as Vercel, Netlify, or GitHub Pages for a client-accessible URL.
